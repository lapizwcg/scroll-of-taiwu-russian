## Установка

**Готовый установщик:** [`installer/TaiwuRussian-0.3.0-setup.exe`](installer/)
Ищет игру сам (Steam, `X:\Games`, `X:\SteamLibrary`, репаки), есть кнопка «Найти
игру на дисках». Английские оригиналы прячет в `TaiwuRussian_backup` внутри папки
игры, удаление возвращает их на место.

**Вручную:**

1. `translation/Language_RU` → `The Scroll of Taiwu_Data\StreamingAssets\Language_RU`
2. `translation/Language_RU/CommonTip\*` → **поверх**
   `StreamingAssets\Language_EN\CommonTip` (подсказки игра читает только оттуда)
3. `translation/EventLanguages\*_Language_RU.txt` → `Event\EventLanguages\`,
   и каждый файл ещё раз — **поверх** одноимённого `_Language_EN.txt`
   (загрузчик событий про суффикс `_RU` не знает)
4. По желанию `mod/prebuilt` → `Mod\TaiwuRussian` — мод возвращает перевод
   на место после обновления игры и подгоняет размер шрифта

Включить: **Настройки → Язык игры → Русский**, затем перезапустить игру.

> Раздел модов зависает, когда язык игры русский: `LocalStringManager` знает
> только CN/EN/KO/CNH/JP. Обходной путь — переключиться на английский, зайти
> в моды, вернуть русский. Это ограничение самой игры.

(238 таблиц `.tsv`) не тронуты и в поставку не входят: игра возьмёт их из
`Language_EN` сама.

## Как продолжить перевод

Прочитать **`CLAUDE.md`** целиком — там формат, глоссарий и десяток ловушек,
на которые уже наступили. Самое важное в трёх строках:

- строки чередуются: нечётная — ключ, чётная — значение; **число строк в RU-файле
  обязано совпадать с EN-файлом**;
- UTF-8 **без BOM**, переводы строк **LF**; перенос внутри значения — литеральное
  `\n`, а в файлах событий — тег `<NL>`;
- кавычек-ёлочек `«»` в шрифте игры нет, рисуется пустой квадрат.

Рабочий цикл:

```bash
python tools/listw.py <файл>                    # сколько осталось
python tools/dump.py <файл> <префикс> out.txt   # выгрузить непереведённое
# ... написать JSON вида {"файл.txt": {"ключ": "перевод"}} ...
powershell -File tools/apply-ru.ps1 -Batch b573.json
python tools/fixquotes.py --apply               # проверка запрещённых знаков
python tools/xfer.py --apply                    # автоперенос по совпадающим строкам
python tools/taiwu-ru-status.py                 # счётчик + проверка целостности
python tools/coverage.py                        # пересобрать карту покрытия
```

Диалоги идут в два шага: `tools/evru.py` правит `*_Language_RU.txt` по словарю
`{английская строка: перевод}`, затем `tools/evdeploy.py --apply` кладёт результат
поверх английского файла — иначе игра перевода не увидит.

**Пути в скриптах прописаны как `C:\Games\...`** — под свою машину поправить
константы `BASE` / `GAME` / `RU` в начале файла.

## Оговорки

Перевод любительский, без участия разработчиков (ConchShip Games). Здесь только
файлы перевода — ничего из самой игры не распространяется. Обновление игры
затирает `StreamingAssets` и `Event`, поэтому копию перевода держите вне папки
игры, а после обновления ставьте заново.

Если возьмётесь продолжать — держитесь глоссария из `CLAUDE.md`: половина работы
там ушла на то, чтобы одна и та же сущность звалась одинаково во всех 148 тысячах
строк.
