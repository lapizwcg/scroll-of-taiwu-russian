# Журнал перевода

Правила и глоссарий — в `CLAUDE.md` рядом с этим файлом.

## Как считать прогресс

```
set PYTHONIOENCODING=utf-8
python taiwu-ru-status.py                 # всё сразу + проверка числа строк
python taiwu-ru-status.py LK_Combat_      # по префиксу ключа
```

**Не считать через `awk`/`grep` с диапазоном `[А-Яа-яЁё]`** — здешний awk работает
с байтами, и такой шаблон ложно срабатывает на «—», «…», «○», «·». Из-за этого
остаток занижается, а строки с длинным тире выглядят переведёнными. Скрипт на Python
сравнивает настоящие кодовые точки `U+0400–U+04FF`.

поэтому разбор с возвратом обязателен.

волость Аньлэ, крепость Аньцю, станция Ансу, застава Аньян, гора Баофу.
Тибетские имена (`Zang_*`, 119 штук) переведены отдельным словарём.

**Терминология уточнена по замечаниям игрока** (партия «переименование»): стряпня →
кулинария, звездочётство → астрология, необычное оружие → экзотическое оружие,
срок жизни → долголетие, а основное свойство `Concentration` (Willpower) —
теперь **воля**, чтобы не путалось с боевым сосредоточением.
Отклонены с обоснованием: словесность → красноречие (слово занято под Argument
в диспуте), проворство → ловкость (занято под Nimble, 89 строк), понимание →
восприятие (смещение смысла), костяк → основа/скелет.

**`ProtagonistFeature_language.txt` закрыт полностью** — 48 особенностей создания
персонажа (происхождение, достаток, ремёсла), их описания и действие. Пользователь нашёл
этот пробел по скриншоту: колонки «Особенности происхождения / достатка / ремёсел»
брали названия не из `CharacterFeature_language.txt`, а из отдельного файла.

**Названия предметов готовы во всех вещевых файлах:** оружие (939), броня (583),
снадобья (441), припасы (350), разное (539). Описания — отдельная задача.

**`Weapon_language.txt`:** все 939 названий готовы, описаний 89 из 939.

Ряды однотипных названий (шкуры, чешуя, яйца цзяо, личинки гу, токсины и их пары)
собраны скриптами: перечисляем диапазоны ключей и подставляем нужную форму слова.
Для родительного падежа у названий цзяо заведена таблица из двух форм — иначе
«Яйцо цзяо, укрытый горой» вместо «укрытого горой».

### Особенности персонажа — где что

Экран создания персонажа собран из двух источников: интерфейс — `LK_NewGame*` и
`UI_NewGame*` (готовы), а раздел «Происхождение и особенности» берёт тексты из
`CharacterFeature_language.txt`: `Name_*` (899, готово), `Desc_*` (841, идёт),
`EffectDesc_*` (197), `SmallVillage*` (13).

**Описания пишутся без указания пола.** Английское «they» в русском требует рода,
поэтому `Desc_*` строятся безличными оборотами и именными группами:
«Крепкое сложение и полнота жизненных сил», «Вечно берётся за непосильное».
Так текст одинаково годится и для мужчин, и для женщин.
