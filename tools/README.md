# Скрипты

Все пути внутри скриптов прописаны под `C:\Games\...` — под свою машину поправьте
константы `BASE`, `GAME`, `RU`, `EN` в первых строках файла. Питону нужен
`PYTHONIOENCODING=utf-8`, иначе вывод кириллицы падает на Windows.

## Применение перевода

| Скрипт | Что делает |
|---|---|
| `apply-ru.ps1 -Batch <файл.json>` | Патчит `*_language.txt` по ключам. Формат: `{"файл.txt": {"ключ": "перевод"}}`. Пишет сразу в игру и в копию мода, сообщает о ключах, которых не нашёл |
| `bulk.py <файл> <словарь.json> <выход.json>` | Раздаёт перевод по дословным повторам внутри файла: словарь `{английская строка: перевод}` → готовая партия по ключам |
| `dcheck.py <файл> <словарь.json>` | Проверяет словарь для `bulk.py` до применения: какие английские строки не найдены среди непереведённых |

## Счётчики и проверки

| Скрипт | Что делает |
|---|---|
| `taiwu-ru-status.py [префикс]` | Главный счётчик + **проверка числа строк** относительно английских файлов |
| `taiwu-ru-byfile.py` | Остаток по каждому файлу |
| `listw.py <файл>` | Остаток в одном файле |
| `coverage.py` | Пересобирает `docs/coverage.md`: покрытие по категориям, по файлам и по пакетам диалогов |
| `fixquotes.py [файл] --apply` | Ищет знаки, которых нет в шрифте игры (ёлочки, типографские кавычки, минус U+2212) и заменяет на допустимые |

## Поиск

| Скрипт | Что делает |
|---|---|
| `dump.py <файл> <префикс> <выход>` | Выгружает непереведённые пары «ключ — английский текст» |
| `gr.py <кусок> [N]` | Ищет английскую строку по всем файлам |
| `gr2.py <кусок> [N]` | То же, но показывает **только уже переведённые** пары — так ищут принятый вариант термина |
| `exact.py <строка> [--bad]` | Поиск по точному совпадению значения |
| `findgap.py <строка>` | Показывает только непереведённые пары — когда игрок присылает скриншот с английским текстом |
| `uibad.py <кусок ключа>` | Непереведённые пары `ui_language.txt` по подстроке ключа |
| `pfx.py <файл>` | Разбивка остатка по префиксам ключей |

## Автоперенос

`xfer.py --apply` строит словарь «английская строка → русский перевод» по всем
готовым парам во всех файлах и заполняет им пустые места. Закрытие одного файла
обычно вытягивает сотни строк в других. Осторожно с короткими строками: одно
английское слово в разных экранах значит разное (`Back` в бою — «Сзади»,
в приключении — кнопка «Назад»), для этого внутри есть список `BLOCK` и
`MINLEN` — пополнять их, а не отключать проверку.

## Диалоги и подсказки (то, что игра читает только из английских папок)

| Скрипт | Что делает |
|---|---|
| `evdump.py <пакет> <выход>` | Уникальные непереведённые реплики пакета событий |
| `evru.py <пакет> <словарь.json> --apply` | Делает `*_Language_RU.txt` и подменяет реплики. **Откажется писать**, если в переводе настоящий перенос строки вместо `<NL>` |
| `evdeploy.py [имя] --apply` | Кладёт русский файл поверх английского — без этого шага игра перевода не увидит. `--restore` возвращает английский из резерва |
| `tipru.py` | Переводит `CommonTip\*.json` текстовой заменой по точному совпадению — теги и подстановки не страдают |
| `tipdeploy.py --apply` | Кладёт русские `.json` поверх `Language_EN\CommonTip` |

`evdeploy.py` и `tipdeploy.py` требуют резервную копию английских оригиналов
(`taiwu-ru-backup\EventLanguages_EN_original`, `taiwu-ru-backup\Language_EN_original`)
и отказываются трогать файл, для которого резерва нет. Резерв делается один раз
обычным копированием перед первым применением.

## `oneoff/`

Разовые скрипты под конкретные правки: генераторы партий по образцу
(`gen*.py`), массовые замены терминов (`tough.py`, `refine.py`, `emperor.py`,
`shorten.py`), правка строк по номеру там, где сбита чётность ключ-значение
(`polytail.py`, `polymeet.py`, `dupkey.py`). Лежат как образцы: когда понадобится
похожая массовая правка, быстрее переделать готовый скрипт, чем писать заново.
